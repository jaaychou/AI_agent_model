## 四、关键技术坑（踩过的，别再踩）

1. **Ollama CUDA 报错** `device kernel image is invalid` → 启动脚本设 `OLLAMA_LLM_LIBRARY=vulkan` 走 Vulkan。驱动 621.24 后理论上可切回 CUDA 未验证
2. **qwen2.5-coder:7b 工具调用非标准**：输出 JSON 文本而非 tool_calls 字段 → `parse_tool_calls()` 兼容层解决
3. **工具结果回灌必须原样**：用 `answer["raw_message"]` 里的 tool_calls（含 index 字段）回灌，自己 json.dumps 重建会报 `Value looks like object, but can't find closing '}' symbol` 400
4. **system prompt 里不能有花括号/JSON 示例**：触发 Ollama 模板解析 bug
5. **tkinter pack 顺序**：必须先 pack 底部(side=BOTTOM)元素，最后 pack 主体(fill=BOTH,expand)，否则输入框被挤出窗口
6. **资源爆满会蓝屏**：曾发生 0x00000119 显卡超时蓝屏（加载 5.6GB 文本编码器 + 6.2GB UNET 时）。已写 `guard\resource_guard.py` 三级防护（SOFT 限流 / HARD 中断+卸载模型 / CRITICAL 杀进程），生图务必开守护
7. **国内下载**：GitHub 走 gh-proxy.com，HuggingFace 走 hf-mirror.com 或 ModelScope（最快 ~5MB/s），Ollama 官方源极慢（23KB/s）
8. **COM 组件被工具沙箱拦截**：创建快捷方式用 `venv-webui` 的 pywin32 写 .py 脚本执行
9. **Ollama partial blob 卡 99%**：不要手删 -partial-N 碎片，把完整 -partial 改名为正式 blob 再 pull
10. **沙箱后台进程跨调用不存活**：验证类操作必须在单次命令内完成；用户实际用 .bat/桌面图标则常驻
