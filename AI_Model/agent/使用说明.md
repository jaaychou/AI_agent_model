# 本地 Agent 使用说明

一个跑在本机、用本地 Ollama 模型驱动的 AI Agent，类似 Claude Code / Codex。

**模型和对话历史在本机运行，不花云端积分。**配置浏览器、邮箱或 GitHub MCP 后，相应 MCP 工具会访问外部服务。

## 启动（推荐：桌面图标，最简单）

**桌面已经有一个「本地AI Agent」图标，双击就打开完整窗口。**

- 不用开 BAT、不用开浏览器
- Ollama 没运行会自动拉起来
- 点击左上角 `☰` 打开侧栏；模型和工作空间在“设置”页，底部输入框输入任务，`Enter` 发送，`Shift+Enter` 换行（`Ctrl+Enter` 也可发送）
- 输入区“＋ 图片”可附加 PNG/JPG/JPEG/WEBP/BMP 图片；图片由 Ollama 视觉模型识别
- 也可附加常见代码或文本文件（单个不超过 200 KB）；图片单个不超过 15 MB
- 点击顶栏左侧 `☰` 展开/收起功能侧栏：会话、知识库、终端、Git、技能、MCP、设置和执行日志都在侧栏内
- Ollama 回复会逐段流式显示，不必等整轮生成结束
- 推理模型尚未生成答案时，状态栏会显示推理活动进度；内部推理原文不会混进最终回答
- 打开侧栏后可拖动聊天与侧栏之间的分隔条；输入框随聊天栏宽度缩放，窗口改变大小时会保持分栏比例。常用按钮有淡色悬停反馈
- 模型能力会显示在状态栏：`qwen2.5vl:7b` 只支持看图聊天；`qwen3.5:4b` 支持看图和 Agent 工具；代码任务可选 `qwen2.5-coder:7b` 或 `deepseek-r1:8b`
- 想同时看图和操作文件时，在侧栏“设置”选择 `qwen3.5:4b`；纯文本模型无法识别图片
- 如果选了不带工具的模型，却提出打开应用、运行命令、操作文件、查设备或生图等任务，GUI 会在检测到本地可用模型后自动切换到支持工具的模型；没有可用工具模型时会明确告知，不会伪称执行成功
- Agent 回复中的 Markdown 标题、粗体、行内代码和 fenced 代码块会在对话中即时渲染。流式输出期间代码块也会逐步显示

如果桌面图标丢了，双击 `scripts\创建桌面快捷方式.bat` 重新生成。

### 备选：命令行版本

如果更喜欢终端，双击 `scripts\5-启动本地Agent.bat`，用法见下面的交互命令部分。

### 直接输入需求

比如"帮我看看这个目录里有什么文件"，Agent 会自己读文件、跑命令、改代码，直到完成。

## 它跟普通聊天有什么区别

普通聊天只能"说"，Agent 能"做"。它会：

1. 理解你的需求
2. 自己决定调哪个工具（读文件、搜索、执行命令）
3. 看工具返回的结果
4. 继续下一步，直到任务完成

全程自主循环，你只管下指令。

## 内置工具

| 工具 | 用途 |
|---|---|
| `read_file` | 读工作空间内的文本文件 |
| `write_file` | 创建/覆盖文件 |
| `delete_file` | 删除单个工作空间文件（每次弹窗确认；不支持整目录删除） |
| `list_dir` | 列目录 |
| `search_files` | 按通配符找文件（如 `*.py`） |
| `grep` | 在文件内容里搜关键词 |
| `run_command` | 在工作空间目录后台执行终端命令（每条命令都弹窗确认，最长 120 秒） |
| `workspace_info` | 查看当前工作空间 |
| `list_skills` / `read_skill` | Skill 相关 |

**权限边界**：默认文件读写、搜索和删除限制在当前工作空间；如在设置中确认开启完整本地访问，读/搜索范围可扩展到工作空间之外，外部写入、删除仍需逐次确认。执行每条命令都需你确认。命令在后台线程运行，工作目录设为当前工作空间并有 120 秒超时。它不是 Windows 操作系统沙盒：确认后命令仍按当前 Windows 用户权限运行，可能访问工作空间以外资源。不要确认不认识或不信任的命令。

## 侧栏功能

历史记录从此版本开始保存到本机 SQLite；此前未持久化的旧聊天不会自动补回。

- **会话**：历史对话保存在本机 `agent/data/history.sqlite3`，可双击或选中后打开，也可确认后删除。对话标题取自首条提问。
- **知识**：在当前工作空间添加和管理本地 RAG 文件。
- **终端**：选择 PowerShell 或 CMD 输入命令；每条命令运行前都会确认，最多 120 秒。
- **权限设置**：可勾选“允许访问工作空间以外的本机文件”；启用时会二次确认，外部删除/写入与命令仍逐次确认。管理员身份需点“以管理员身份重启”，并在 Windows UAC 窗口中确认；UAC 未确认不会提权。管理员模式可通过“切换到普通用户模式”返回。
- **文生图**：使用支持工具调用的模型提出“生成一张……图片”，Agent 会确认后调用本机 ComfyUI 的 Z-Image-Turbo，必要时在后台启动 ComfyUI。为让出显存，会先卸载驻留的 Ollama 模型（下一轮会自动重新加载）。生成结果嵌入对话并保存于 `AI_Model/ComfyUI/output/`。尺寸上限 1024，步数上限 12；启动及生成受内存/显存预检保护。
- **Git**：读取当前工作空间的分支、文件状态、远程地址和最近提交。提交、拉取、推送等写操作可在终端执行，并需确认。
- **技能**：导入包含 `SKILL.md` 的文件夹；新技能在下一条任务加载。技能说明会进入模型上下文，请只导入可信内容。
- **MCP**：添加本地 MCP Server 的启动命令、参数和环境变量。支持的浏览器、邮箱、GitHub 能力取决于你安装和授权的具体 MCP Server。服务会在 Agent 创建时启动；每次 MCP 工具调用都需确认。
- **Windows 桌面工具**：`system_info`/`workspace_info` 查询真实系统和工作空间；`query_devices` 通过 Windows 即插即用设备清单查询设备；`open_vscode` 可打开并检测 VS Code 可见窗口；`execute_command` 是 `run_command` 的别名。
- **浏览器**：已预装 Microsoft Playwright MCP 和 Edge 集成。首次使用会打开一个专用于 Agent 的 Edge 用户资料目录；它与日常 Edge 登录隔离，需在 Agent 控制的窗口登录站点。网页上的写入/提交操作仍需确认。

Playwright MCP 使用隐藏的后台进程，不应再弹出 Node 控制台窗口。Agent 会按当前请求筛选浏览器工具；一般聊天和本机文件任务不会把全部浏览器工具定义塞进模型上下文。

MCP 环境变量可用 `${VARIABLE_NAME}` 引用 Windows 环境变量，避免把令牌明文写入 `mcp_servers.json`。本 GUI 不会替你登录邮箱或浏览器，也不内置某个平台的 OAuth 流程。

**终端和 MCP 安全边界**：CMD/PowerShell 子进程以当前 Windows 用户权限运行，工作目录是工作空间，但这不是操作系统沙盒；命令可能访问工作空间以外资源。设置页的“允许 Agent 自主运行 PowerShell / CMD 命令”开启后，Agent 会不经逐条弹窗运行命令并根据结果继续排错；关闭后每条命令都会确认。管理员权限只在通过 Windows UAC 以管理员身份启动 GUI 后才有。MCP 服务也可能访问其获授权的外部数据；只添加可信服务，并仔细查看授权范围。

“允许访问工作空间以外的本机文件”与“管理员身份”是两种独立设置。前者放宽 Agent 文件工具的路径限制；后者由 Windows UAC 授予进程管理员令牌，可能访问普通账户无法访问的系统资源。只在确有需要时使用管理员模式。

## Git 仓库

点击顶栏 `☰`，打开“Git”标签。这里始终对当前工作空间操作：

1. “初始化本地仓库”会创建 `main` 分支；若工作空间根目录没有 `.gitignore`，会先生成一份忽略虚拟环境、凭据、数据目录、模型权重和输出文件的模板。
2. 填写提交者姓名和邮箱后点“保存本地身份”；这只设置当前仓库的 Git 身份。
3. 粘贴 GitHub/GitLab 的 HTTPS 或 SSH 仓库 URL，点“设置 origin”。私有仓库凭据通过 Git Credential Manager 或 SSH key 提供，不要把 Token 写入 URL。
4. 可以克隆仓库到所选目录，或对当前仓库执行快进拉取、暂存并提交、推送。拉取、提交、推送会先显示确认；推送会把当前提交发到远端。
5. 点“刷新状态”检查当前分支、工作区改动、远端和最近提交。

## 本地知识库（RAG）

1. 点击顶栏 `☰`，再打开“知识”标签。
2. 点击“添加 / 重新索引”，可以从本机任意位置选文件；索引在不同工作空间间共享。
3. 关闭窗口后直接提问；Agent 会自动检索最多 3 段相关片段（总长约 1800 字符），并要求模型根据来源回答。
4. 文件更新后再次添加同一文件即可重建索引；“移除所选”只从知识库索引移除，不删除原文件。

支持 PDF、DOCX、TXT、Markdown、CSV、JSON、YAML、常见代码和文本格式。索引使用 SQLite FTS5 本地全文检索，不下载/常驻额外向量模型；中文按字符片段检索，语义改写和同义词匹配能力弱于向量检索。PDF/DOCX 表格、扫描件和图片里的文字不保证能抽取；扫描 PDF 需要先 OCR。PDF 解析依赖已在 Agent 的 `venv-comfy` 环境安装的 `pypdf`（也可运行 `pip install -r requirements.txt`）。

知识库数据保存在 `agent/data/knowledge/` 的共享 SQLite 索引中，不会上传网络。索引不会自动监视文件变更，需要重新添加已修改文件。旧版工作空间专属索引文件仍留在原处；新增的共享索引不自动导入旧索引。

## 运行进度

Agent 运行任务时，窗口顶部会显示当前阶段、已用时间、预计剩余时间和进度百分比。对话/代码生成的百分比根据模型与任务类型的历史耗时估算；第一次运行使用默认估值，之后会按近几次实际耗时校准。图片生成会显示 ComfyUI 准备、启动和生成阶段。模型接口和 ComfyUI 没有统一的精确总进度，因此显示的是估算值，任务完成后才显示 100%。

## 模型选择

- **qwen2.5-coder:7b**（默认）：最快，5 秒响应，代码能力强。工具调用格式非标准，但已做兼容层处理
- **qwen3.5:4b**：标准工具调用，稳，但慢（40 秒左右）
- **deepseek-r1:8b**：深度推理，适合复杂规划，很慢
- **流式输出**：四个当前模型都使用 Ollama `/api/chat` 流式响应。DeepSeek-R1 和 Qwen3.5 往往先输出内部 thinking 活动，因此可见回答可能稍晚开始；thinking 只更新进度，不显示原文。`qwen2.5vl:7b` 支持看图但不支持工具，操作任务会由 GUI 自动切到可用的工具模型。

模型上下文由 Ollama 设置为 8192 token；聊天历史只保留最近 16 条，且与当前任务无关的 MCP 工具不会发送给模型。对普通问答和简单操作，Qwen3.5 / DeepSeek-R1 会关闭冗长思考；复杂排错、分析和多步实现仍保留思考。若思考模型只返回思考没有答案，会自动关闭思考重试一次。

建议日常用 coder，遇到复杂任务或需要同时看图和使用工具时切 qwen3.5:4b。`qwen2.5vl:7b` 只看图、不支持工具；需要操作时 GUI 会自动切换模型。纯文本模型不能识别图片。要在聊天里文生图，输入“生成一张……”，Agent 会调用本机 ComfyUI 的 Z-Image-Turbo；服务不可用或生成失败时会报告错误，不会假称成功。ComfyUI 服务需可启动且模型文件完整；生成请求会提示确认。

## Skill 机制

Skill 是一个带 `SKILL.md` 的文件夹，放在 `skills\` 目录下。Agent 启动时会加载简介，需要时用 `read_skill` 读取完整说明。

已内置 4 个技能（截至 2026-11-23 19:26:45）：
- `code-review`：代码审查（16:13:50）
- `file-organizer`：文件整理（16:13:59）
- `windows-desktop-operations`：Windows 设备查询 / 打开 VS Code（18:13:47，Codex 新增）
- `browser-automation`：Playwright 浏览器自动化（18:19:34，Codex 新增）

自己加技能：新建 `skills\我的技能\SKILL.md`，格式：

```markdown
---
name: 技能名
description: 一句话描述
triggers: 触发词1, 触发词2
---

# 技能说明
在这里写详细的执行步骤……
```

## MCP 支持

MCP = Model Context Protocol，可以让 Agent 用外部工具（浏览器、数据库、GitHub 等）。

配置文件：`mcp_servers.json`

```json
{
  "mcpServers": {
    "我的服务": {
      "command": "python",
      "args": ["D:/path/to/mcp_server.py"],
      "env": {}
    }
  }
}
```

启动时自动连接，外部工具会以 `mcp_服务名_工具名` 的形式加入工具列表。协议已实测通过。

## 以后接云端 API

`core/llm.py` 里已经写好了 `OpenAICompatibleProvider` 类。以后要接 DeepSeek / OpenAI API，只需改配置文件和初始化代码：

```python
from core.llm import OpenAICompatibleProvider
provider = OpenAICompatibleProvider(
    base_url="https://api.deepseek.com/v1",
    api_key="sk-xxx",
    default_model="deepseek-chat",
)
```

Agent 核心、工具、Skill、MCP 全都不用动。

## 已知限制

- 本地 7B 模型能力有天花板：能干简单到中等复杂度的任务，复杂长程任务会跑偏
- 上下文窗口受 Ollama 当前运行配置限制；保留消息数不等于模型能读下全部内容
- 命令行工具在 Windows 上用的是 cmd 语法
