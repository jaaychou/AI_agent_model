# 代码审查技能

当用户要求审查代码时，按以下步骤执行：

1. 用 `read_file` 读取目标文件的完整内容
2. 逐项检查：
   - 语法错误和明显的逻辑 bug
   - 边界条件（空值、越界、异常输入）
   - 安全问题（SQL 注入、路径穿越、敏感信息泄露）
   - 性能问题（不必要的循环、重复计算）
   - 代码风格和可维护性
3. 用 `grep` 搜索相关函数在其他地方的调用，确认改动影响范围
4. 输出简洁的审查报告，按严重程度排序：严重 / 一般 / 建议
5. 每个问题给出文件名、行号、问题描述和修复建议

注意：只报告真实问题，不要为了凑数编造问题。没问题就明确说"未发现问题"。
