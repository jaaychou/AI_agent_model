## 资源守护（防卡死，重要！）

之前发生过两次意外关机：一次是系统卡死后强制断电，一次是 **0x00000119 蓝屏**（显卡引擎超时）。原因基本锁定为：加载 6GB UNET + 5.6GB 文本编码器时，显存和系统内存同时冲顶。

`guard\resource_guard.py` 就是为此写的，双击 `scripts\0-启动资源守护.bat` 常驻即可：

| 级别 | 触发 | 自动动作 |
|---|---|---|
| SOFT（黄） | 可用内存 < 2200MB / 显存 > 80% / 温度 > 82°C | 降低相关进程优先级，限制 CPU 核心数 |
| HARD（红） | 可用内存 < 1400MB / 显存 > 90% / 温度 > 88°C | 向 ComfyUI 发 `/interrupt` 中止当前生成 + `/free` 卸载模型释放资源 |
| CRITICAL | 可用内存 < 900MB / 显存 > 96% / 温度 > 92°C | 强制终止 ComfyUI 进程，响铃报警，保住系统 |

- 阈值都在 `guard\guard_config.json`，可自己改
- 每次动作有 45 秒冷却，不会反复折腾
- 事件记录：`guard\guard.log` 和 `guard\guard_events.jsonl`
- 只观察不动作：`python resource_guard.py --dry-run`
- 看当前指标：`python resource_guard.py --once`

生图脚本 `zimage_generate.py` 另有提交前预检：边长 >1024、步数 >12、可用内存 <1400MB、显存占用 >85% 时直接拒绝提交。

### 启动脚本排错

1、Ollama 的 11434 端口已占用通常代表服务已经在运行。更新后的 Ollama 启动器会先请求本地 API，发现已有服务就提示并退出，继续使用现有服务即可。

3、Open WebUI 日志中的 CORS_ALLOW_ORIGIN='*' 是配置警告，不代表启动失败；服务监听 127.0.0.1 时只绑定本机回环地址。

### 本机 Agent 文件操作与命令执行

Agent 已有可回读核验的文本创建/精确修改、文件查找、单文件复制/移动/删除和哈希检查；Office 新格式支持提取文字，ZIP 支持安全列出/创建/解压。EXE 等二进制可检查与搬运，但不会被伪装成文本写入，也不会被自动运行。详细能力边界、格式限制和测试记录见 `agent/使用说明.md` 的“本机文件操作与任务闭环”。

## 让 Agent 自己扩展能力（元工具）

Agent 不再只会调用写死的工具。遇到做不了的任务，它会自己找办法：

- **发现能力**：`discover_tools` 列出全部工具，`inspect_environment` 看本机现成的库和命令。
- **联网找工具**：`search_tools` 搜 PyPI 真实包（实测可用），`web_search` 搜其他来源。
- **隔离安装**：`install_package` 把包装进 `agent/runtime/vendor`，不污染你的 Python 环境，会弹窗确认。
- **自己造工具**：`create_tool` 把一段 Python 代码变成永久工具，以后对话都能用；脚本存 `agent/dynamic_tools/`。写工具时不能 import subprocess/socket 等危险模块（有静态检查），也不能用 eval/exec。

对 Agent 直接说"你有什么工具""装个能读 excel 的库""写个工具帮我做 X"，它就会走这套流程。详细流程见技能 `self-extension`。

### 底层控制工具

- 看状态：`system_status`（CPU/内存/磁盘）、`serial_ports`（COM 口）、`list_windows`（确认软件是否真打开）、`env_vars`（自动隐藏密码/令牌）。
- 进程/服务：`list_processes`、`list_services` 只读；`terminate_process`、`service_control` 会弹窗确认。
- 注册表：`registry_read` 只读 HKLM/HKCU。
- 更底层的命令行操作用 `run_command`，按当前用户权限运行，不是沙盒。

安全：装包/造工具/结束进程/改服务都要你确认；Agent 不会索要密码、绕过 UAC 或窃取凭据。装的包想卸载，删 `agent/runtime/vendor` 对应文件夹并清空 `agent/runtime/tool_index.json` 里的 packages 即可。

### 网页抓取与串口

- `web_fetch`：给一个网址抓网页正文和链接，用于读网页/文档/做研究。只访问公网 http(s)，拒内网地址、查 robots.txt；本机代理会导致证书验证失败，工具会自动降级并在结果里标注。JS 动态页面或要登录的，用浏览器工具（Playwright MCP）。
- `serial_comm`：串口 `list` 查看 COM 口；`read/write/write_read` 读写指定串口，写入会弹窗确认。读写需要 pySerial，让 Agent 用 `install_package(package="pyserial")` 装一下即可。

在 L4 之上又加了一层**围栏内的长期自治**——给它一个目标，它能在白名单工具、时限和轮数内自己观察→决策→行动→验证地循环，不用你逐轮下令；但一旦越界、超时或连续失败就自动停机，写操作仍需你确认，你也能随时喊停。这不是"放养式全自动"。直接对 Agent 说"用 autopilot 完成 X"即可；围栏配置见 `core/autopilot.py` 的 `Fence`。
