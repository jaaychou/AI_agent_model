## 怎么启动

### 日常对话（三步）

1. **双击** `scripts\1-启动Ollama.bat` —— 模型服务，保持窗口开着
2. **双击** `scripts\2-启动WebUI.bat` —— 网页界面，保持窗口开着
3. 浏览器打开 **http://localhost:8080**，注册账号（本地的，随便填）就能用

> 命令行直接用：`D:\Program\AI_Model_agent\AI_Model\Ollama\ollama.exe run qwen3.5:4b`

### 本地生图（推荐先开守护）

1. **双击** `scripts\0-启动资源守护.bat` —— 防止资源爆满导致卡死/蓝屏（保持开着）
2. **双击** `scripts\3-启动ComfyUI.bat` —— 保持窗口开着
3. 浏览器打开 **http://localhost:8188**，在界面里手动搭工作流；或直接用命令行脚本生成：

```bash
"D:\Program\AI_Model_agent\AI_Model\venv-comfy\Scripts\python.exe" ^
  "D:\Program\AI_Model_agent\AI_Model\scripts\zimage_generate.py" "描述文字" --width 512 --height 512 --steps 8
```

生成结果自动存到 `ComfyUI\output\ZImage_xxxxx.png`。脚本默认参数：512×512、8 步、CFG=1、种子 42，支持 `--seed`、`--width`、`--height`、`--steps`。

**已实测**：512×512、8 步，34 秒出图，质量正常（戴宇航头盔的猫）。

## 资源守护（防卡死，重要！）

之前发生过两次意外关机：一次是系统卡死后强制断电，一次是 **0x00000119 蓝屏**（显卡引擎超时）。原因基本锁定为：加载 6GB UNET + 5.6GB 文本编码器时，显存和系统内存同时冲顶。

`guard\resource_guard.py` 就是为此写的，双击 `scripts\0-启动资源守护.bat` 常驻即可：

| 级别 | 触发 | 自动动作 |
|---|---|---|
| SOFT（黄） | 可用内存 < 2200MB / 显存 > 80% / 温度 > 82°C | 降低相关进程优先级，限制 CPU 核心数 |
| HARD（红） | 可用内存 < 1400MB / 显存 > 90% / 温度 > 88°C | 向 ComfyUI 发 `/interrupt` 中止当前生成 + `/free` 卸载模型释放资源 |
| CRITICAL | 可用内存 < 900MB / 显存 > 96% / 温度 > 92°C | 强制终止 ComfyUI 进程，响铃报警，保住系统 |

- 阈值都在 `guard\guard_config.json`，可自己改
- 每次动作有 45 秒冷却，不会反复折腾
- 事件记录：`guard\guard.log` 和 `guard\guard_events.jsonl`
- 只观察不动作：`python resource_guard.py --dry-run`
- 看当前指标：`python resource_guard.py --once`

生图脚本 `zimage_generate.py` 另有提交前预检：边长 >1024、步数 >12、可用内存 <1400MB、显存占用 >85% 时直接拒绝提交。

## 注意事项

- **散热**：笔记本长时间满载会发热，保持通风。守护程序会主动限流，但别在高温环境连续跑几小时。
- **DeepSeek 回复慢**：它是先思考再回答，简单问题也要想 400+ token，别以为卡住了。
- **qwen3-vl:4b 已删除**：那个版本 Ollama 模板有 bug（thinking 重复触发中止），换成了稳定的 qwen2.5vl:7b。
- **别手删 Ollama 的 `-partial-N` 文件**：下载卡住时删碎片会导致 blob 校验失败，正确做法是把完整的 `-partial` 改名成正式 blob 再重新 pull。
- **Z-Image-Turbo 是文生图，不是生视频**。`diffusion_models` 只是扩散模型目录名，跟视频无关。视频模型（Wan/LTX）没装，也不需要。
