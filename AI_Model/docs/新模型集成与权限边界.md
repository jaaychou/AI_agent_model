# 新模型快速集成 & 权限边界说明（2026-11-24）

## 一、显卡升级 / 租云端服务器后，能不能快速集成新模型？

**能，而且大多是"改配置 + 刷新"，不需要改代码。** 分三种情况：

### 情况 A：还是用 Ollama（本地新显卡 / 本地新模型）

1. 拉新模型：`ollama pull 模型名`（在 `scripts\1-启动Ollama.bat` 的同款环境）。
2. GUI 里点模型下拉框旁的 **「刷新」** 按钮 → 自动调用 `provider.list_models()` 列出新模型。
3. 选中新模型即可。能力探测 (`model_capabilities`) 会自动跑，判断它支不支持 tools / vision。
4. 如果新模型名字不在已知列表里，能力探测会按默认给 tools；若它其实不支持工具，可在提示里说明。

### 情况 B：接云端 / 第三方 OpenAI 兼容 API

1. `core/llm.py` 已有 `OpenAICompatibleProvider(base_url, api_key, default_model)`，支持任意 OpenAI 格式端点（DeepSeek 云、OpenRouter、vLLM、自建服务器等）。
2. 让 Agent 用元工具**自己写适配器**：对 Agent 说"接一个 OpenAI 兼容端点，地址是 xxx"，
   它会用 `create_tool` 或改 `config.json` 的 `base_url` 来接入（API key 放 `api_keys.json`，被 gitignore）。
3. 也可手动在 `agent/config.example.json` 加一段 provider 配置。

### 情况 C：让 Agent 自己探测并配置（已具备）

- `inspect_environment`：查本机 Python、命令行工具、已装库。
- `discover_tools` / `search_tools`：发现现有能力、联网找新工具。
- `delegate_to_model` / `list_models_capability`：**多模型协同**——A 模型可把子任务交给更擅长的 B 模型（实测成功）。
- `install_package` / `venv_manager`：隔离装依赖、建虚拟环境。
- 结论：换新硬件后，Agent 能自己探测环境、识别新模型、刷新 GUI 列表、必要时装依赖或写适配器。
  **注意**：真正"改 GUI 源码"仍建议由你确认（Agent 会走 confirm），避免它自改 UI 改坏。

## 二、我给了完全访问权限，还有 Agent 拿不到的权限吗？能让 Agent 获取吗？

**诚实答案：有，而且理论上你有的权限 Agent 大多能继承，但有几类它拿不到或不该拿——这是设计边界，不是 bug。**

### Agent 已经能做的（继承你的权限）

- 读写本机文件、运行命令、控制进程/服务/窗口、串口、注册表只读、安装包、联网、抓包（需管理员）。
- 以管理员身份运行时，命令也带管理员权限（靠 GUI 的 UAC 重启按钮）。

### Agent 拿不到 / 不该拿的

| 类型 | 为什么 | 怎么办 |
|---|---|---|
| **UAC 提权本身** | Windows 不允许程序静默绕过 UAC（这是系统安全底线） | 你点"以管理员身份重启"，在 UAC 弹窗点允许 |
| **邮箱/网站登录密码** | 只认授权码且存 Windows 凭据保管库；Agent 不索要、不保存主密码 | 你在设置页填 IMAP/SMTP 授权码 |
| **BIOS/固件写入** | 用户态无法安全刷写，刷坏变砖；必须厂商工具+你确认 | Agent 只给指引，绝不放手自动刷 |
| **其他人/其他账户的数据** | 权限隔离，且法律/隐私边界 | 不碰；需要时你本人操作 |
| **物理操作**（插U盘、按电源、BIOS 设置界面） | 没有物理手 | 你做，Agent 给步骤 |
| **抓包/蓝牙空口的硬件能力** | Windows 商用网卡多数不支持 monitor、BLE 嗅探需专用硬件 | 工具如实报告，不伪造 |
| **登录态/双因素验证码** | 需要你的手机/二次验证 | 你完成验证，Agent 不代填 |

### 一句话总结

你给的是"当前 Windows 账户的执行权限"，Agent 继承它；但 **UAC、密码、凭据、物理操作、硬件限制、他人数据** 这几类，
要么系统不允许程序自动拿，要么不该让 AI 拿。这不是"想办法就能绕过"的——绕过它们等于突破操作系统安全模型，
我不会做，也不建议做。真正需要时，正确姿势是**你授权一次，Agent 在授权范围内干活**。
