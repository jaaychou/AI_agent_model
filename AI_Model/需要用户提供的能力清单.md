- **怎么用**：把 Key 填进 `D:\Program\AI_Model_agent\AI_Model\agent\api_keys.json` 的 `tencent_map_key` 字段（复制 `api_keys.example.json` 改）。填完 `geocode` / `route_plan` / `search_place` 三个工具立刻可用。

### 5. 硬件相关限制（不是配置，是硬件本身）ℹ️

- **WiFi 802.11 监控模式**：绝大多数 Windows 商用网卡不支持，即使有 Npcap 也进不了 monitor mode。`scan_wifi_80211` 会如实报告，不伪造抓到的帧。要真抓无线空口帧需支持 monitor 的 USB 网卡 + 特定驱动。
- **BLE 空口嗅探**：Windows 上 scapy 无法直接嗅探，需专用硬件（nRF Sniffer / Ubertooth）。`scan_ble_beacon` 列的是系统已枚举蓝牙设备，会如实说明。
- **刷 BIOS 固件**：Windows 用户态无法安全刷写，必须厂商官方工具 + 管理员 + 你手动确认（刷坏会变砖）。`bios_update_guidance` 给指引，Agent 绝不无人值守刷固件。
